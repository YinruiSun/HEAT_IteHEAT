# HEAT & IteHEAT

Codes for article:

**Yinrui Sun & Yin Xia. Optimal Integrative Estimation for Distributed Precision Matrices with Heterogeneity Adjustment. _The Annals of Statistics_, 54(5), 2209-2233.**

The file `functions.r` includes the codes to implement the proposed `HEAT` and `IteHEAT` methods.

The file `functions_comparison.r` includes the codes to implement the compared `JGL` and `HGSL` methods.

The file `data_generation.r` includes the codes to generate the simulation data.

The file `demo.html` includes the demo codes to utilize the functions.
